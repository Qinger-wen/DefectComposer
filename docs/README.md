# GitHub Pages demo

This folder contains a dependency-free static demo page for selected
DefectComposer results.

To publish it with GitHub Pages, open the repository settings, choose
**Pages**, select **Deploy from a branch**, and use the repository branch with
the `/docs` folder.

The page renumbers the selected material as Tables 1–3 and Figures 1–2. Table
values and figure captions are transcribed from the LaTeX manuscript without
modification.
